Where your journal lives

Saved entries stay in this browser's local storage, for this exact site address and port. They are not encrypted. Anyone with access to your browser profile may be able to read them. Use a private device.

Clearing site data, using private browsing, changing the address or port, or losing this device can remove access to your journal. Unsaved form text is not stored. Make your own backups.

Keep a copy

A backup is a plain JSON file, not encrypted. Store it somewhere you trust. Exports can contain sensitive personal text.

Restore a backup

Import previews the number of entries before replacement. A supported backup is at most 1 MiB and 200 entries. Replacing your journal removes the current entries from this browser. Export them first if you want to keep them.

Delete this journal

This removes saved entries at this site address. It does not delete downloaded backups. You will be asked to confirm.

About the exercises

These original prompts draw on NHS explanations of thought records and reframing. This prototype is unsupervised and has not been clinically evaluated. It does not provide the trained practitioner support described in formal guided self-help.
